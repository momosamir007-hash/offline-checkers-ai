# Offline Checkers AI v13 Professional

## ما الجديد في v13
- ميزانية زمنية صارمة لتحليل جميع النقلات.
- إصلاح مسار التحكم بالوقت داخل البحث الهادئ (quiescence search).
- استخراج Principal Variation من جدول النقلات.
- إظهار أفضل رد متوقع للخصم لكل نقلة محللة.
- تحسين حساب عدد القطع المأكولة في السلاسل.
- تغطية التحليل: عدد النقلات التي تم تحليلها ضمن الميزانية الزمنية.
- اختبار سلامة ثابت يمنع عودة خطأ `deadline` غير المعرّف.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```
