# Offline Checkers AI v15 Strategic

## ما الجديد
- محرك تحليل استراتيجي شفاف: المادة، الحركة، التهديدات، التقدم ومرحلة المباراة.
- GameTracker لتسجيل المباراة، التحقق من قانونية النقلات، متابعة التكرار والتراجع.
- تحليل سجل المباراة لاكتشاف الأخطاء ونقاط التحول.
- استمرار التحليل التكتيكي لكل النقلة مع أفضل بديل ودرجة الخطأ.
- اختبارات إضافية للتحليل الاستراتيجي وسجل المباراة.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```

> ملاحظة: v15 يركز على قواعد الداما الإنجليزية/الأمريكية كما يطبقها محرك المشروع.
